# Secret Auction Enhanced

## 📖 Description
A secret auction CLI that collects anonymous bids and prints the winner.

---

## ⚙️ Features
- Graphical UI using Tkinter

---

## 🧩 Dependencies
- None (standard library only)

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Use dictionaries and loops to collect, store, and compare user bids in a terminal app.
