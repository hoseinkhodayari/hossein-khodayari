# Leap Year Checker Reimagined

## 📖 Description
Checks whether a provided year is a leap year using standard calendar rules.

---

## ⚙️ Features
- Graphical UI using Tkinter

---

## 🧩 Dependencies
- None (standard library only)

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Understand nested conditionals and logical operators by determining whether a given year qualifies as a leap year.
