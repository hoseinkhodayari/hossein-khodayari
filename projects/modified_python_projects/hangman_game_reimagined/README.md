# Hangman Game Reimagined

## 📖 Description
A number guessing game with random target selection and user interaction.

---

## ⚙️ Features
- Randomized behavior

---

## 🧩 Dependencies

---

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.
