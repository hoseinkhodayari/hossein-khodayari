# Pizza Delivery Reimagined

## 📖 Description
A simple pizza ordering/delivery calculation script that demonstrates input parsing.

---

## ⚙️ Features
- Simple, readable code
- Command-line runnable (unless GUI)

---

## 🧩 Dependencies
- None (standard library only)

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Practice conditional logic, user input handling, and arithmetic operations to calculate customizable order totals.

---

## 📝 Notes & Suggestions
- Consider separating core logic into functions to make the code testable.
