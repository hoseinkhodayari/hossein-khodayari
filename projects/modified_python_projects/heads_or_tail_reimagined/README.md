# Heads Or Tail Reimagined

## 📖 Description
Simulates coin toss (heads or tails) interactions.

---

## ⚙️ Features
- Graphical UI using Tkinter
- Randomized behavior

---

## 🧩 Dependencies
- None (standard library only)

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Learn how to use the random module and conditional statements to simulate simple probability-based outcomes.
