# Prime Number Checker Reimagined

## 📖 Description
A prime number checker that determines whether a given integer is prime.

---

## ⚙️ Features
- Simple, readable code
- Command-line runnable (unless GUI)

---

## 🧩 Dependencies
- None (standard library only)

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Learn how to use loops, conditionals, and modular arithmetic to determine whether a number is prime efficiently.

---

## 📝 Notes & Suggestions
- Consider separating core logic into functions to make the code testable.
