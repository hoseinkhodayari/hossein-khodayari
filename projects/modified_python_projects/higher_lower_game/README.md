# Higher Lower Game

## 📖 Description
A GUI higher/lower game comparing follower counts or numeric data with multiple data files.

---

## ⚙️ Features
- Graphical UI using Tkinter
- Randomized behavior

---

## 🧩 Dependencies
- art
- game_data

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Practice comparison logic, loops, and formatted outputs while working with datasets.
