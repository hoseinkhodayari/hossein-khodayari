# Bill Splitter Reimagined

## 📖 Description
A basic calculator with arithmetic operations and a simple user interface/CLI.

---

## ⚙️ Features
- Simple, readable code
- Command-line runnable (unless GUI)

---

## 🧩 Dependencies
- None (standard library only)

---

## 🚀 How to Run

Run the project:

```bash
python main.py
```

Follow any on-screen prompts.

---

## 🧠 Learning Purpose
Learning the Basics of variables, how to use them in a practical case and creating a functional and helpful bill splitting program.

---

## 📝 Notes & Suggestions
- Consider separating core logic into functions to make the code testable.
